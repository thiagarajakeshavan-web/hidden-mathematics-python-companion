## Assumptions and limitations

Finite differences are checked away from the ReLU corner. The derivative convention at the corner is not a proof of differentiability. All parameters use the same old gradient in an update.

## Experiment and interpretation

Change the difference step over several powers of ten and inspect rounding. Never update one parameter and reuse the altered network to compute another gradient in this example.
