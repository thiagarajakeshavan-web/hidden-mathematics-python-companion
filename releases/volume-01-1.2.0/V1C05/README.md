## Purpose and input

Inputs: x=[1,2],y=[2,4]; objective mean(error²)/2=1.25(w−2)². Start w=0.

All values and datasets are synthetic. This lab supplies executable checks for the matching chapter's mathematics and implementation-pattern discussion.

## Assumptions and limitations

The convergence range 0<rate<.8 belongs to this quadratic and loss normalization. The diagonal inverse-Hessian preconditioner uses curvature known exactly in a toy case; it is not a universal optimizer.
