# V2C22-CASE01: முடிவெடுக்கும் நேரத்தில் அறிந்த தகவல் [Point-in-time Knowledge]

வெளியீடு [Release] 0.1.0; தொகுதி 2, அத்தியாயம் 22. இது செயற்கைக் கற்றல் உள்ளீடு [Synthetic Teaching Fixture].

## நிரல் என்ன செய்கிறது [Program Behaviour]

ஒவ்வொரு விலைப் பதிவுக்கும் நிகழ்வு நேரம் [Event Time] மற்றும் கிடைத்த நேரம் [Available-at Time] உள்ளன. முதலில் குறிப்பிட்ட பொருளுக்கும் முடிவெடுக்கும் நேரத்திற்குள் அறியப்பட்ட பதிவுகளுக்கும் [Known Records] வடிகட்டல் [Filtering] செய்யப்படுகிறது. அதன் பிறகே நகல் நீக்கம் [Deduplication] மற்றும் முரண்பாட்டு தனிமைப்படுத்தல் [Conflict Quarantine] நடக்கின்றன.

## முடிவைப் புரிந்துகொள்ளுதல் [Result Interpretation]

10:00 மணிக்கு A$10 பதிவு இன்னும் கிடைக்காததால் A$12 பயன்படுத்தப்படுகிறது. 10:15 மணிக்கு A$10 கிடைக்கிறது. எதிர்காலத்தில் வரும் முரண்பாடு [Future Conflict] முந்தைய முடிவை மாற்றக்கூடாது. இல்லாத அல்லது காலாவதியான தரவுக்கு [Missing or Stale Data] null வெளியீடு [Output] கிடைக்கும்.

## இயக்குதல் [Run]

துணைத்தொகுப்பின் முதன்மைக் கோப்புறையிலிருந்து [Companion Root]:

    python run_cases.py --chapter 22 --verify

fixture.json கோப்பில் உள்ளீடுகள் [Inputs] உள்ளன. expected.json கோப்பில் உண்மையில் இயக்கிப் பதிவு செய்த வெளியீடு [Recorded Output] உள்ளது. src/volume2_companion/chapter22.py கோப்பில் கணிப்புமுறை [Algorithm] உள்ளது. tests/test_companion.py கோப்பில் அலகுச் சோதனைகள் [Unit Tests] உள்ளன. முதன்மை README_TA.md கோப்பில் நிறுவல் வழிகாட்டி [Setup Guide] உள்ளது.

உள்ளீட்டை [Input] மாற்றும் முன் நகலை [Copy] வைத்துக்கொள்ளவும். அலகுகளையும் [Units] கருதுகோள்களையும் [Assumptions] கவனிக்கவும். எதிர்பார்க்கப்பட்ட கோப்பை [Expected File] மாற்றுவது மட்டும் சரியான கணக்கீட்டிற்கான சான்று அல்ல. இணையம் [Network], கட்டண API [Paid API], அணுகல் சாவி [Credential] அல்லது மாதிரி பதிவிறக்கம் [Model Download] தேவையில்லை.
