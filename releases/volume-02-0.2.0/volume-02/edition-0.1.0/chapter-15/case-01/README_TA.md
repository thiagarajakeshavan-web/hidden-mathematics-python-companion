# V2C15-CASE01: பின்னோக்கிப் பரவலைச் சரிபார்த்தல் [Backpropagation Audit]

வெளியீடு [Release] 0.1.0; தொகுதி 2, அத்தியாயம் 15. இது செயற்கைக் கற்றல் உள்ளீடு [Synthetic Teaching Fixture].

## நிரல் என்ன செய்கிறது [Program Behaviour]

இரண்டு உள்ளீட்டு அம்சங்களும் [Input Features] ஒரு ReLU மறை அலகும் [Hidden Unit] உள்ளன. அளவுரு வரிசை [Parameter Order] w0, w1, b, v, c. எல்லாச் சாய்வுகளும் [Gradients] பழைய அளவுருக்களிலிருந்து கணக்கிடப்பட்ட பிறகே ஒரே நேரத்தில் புதுப்பிக்கப்படுகின்றன [Simultaneous Update]. மைய வேறுபாட்டுச் சோதனை [Central-difference Test] ஒவ்வொரு அளவுருவையும் 1e-6 அளவு மாற்றுகிறது. முதன்மை எடுத்துக்காட்டு ReLU முறிவுப் புள்ளியிலிருந்து [Kink] விலகி உள்ளது.

## முடிவைப் புரிந்துகொள்ளுதல் [Result Interpretation]

இந்த எடுத்துக்காட்டில் இழப்பு [Loss] 0.7339469673 இலிருந்து 0.6789767190 ஆகக் குறைகிறது. இது எல்லாப் பயிற்சிகளுக்குமான உறுதி அல்ல. கற்றல் வீதத்தை [Learning Rate] மாற்றி விளைவைப் பார்க்கவும்.

## இயக்குதல் [Run]

துணைத்தொகுப்பின் முதன்மைக் கோப்புறையிலிருந்து [Companion Root]:

    python run_cases.py --chapter 15 --verify

fixture.json கோப்பில் உள்ளீடுகள் [Inputs] உள்ளன. expected.json கோப்பில் உண்மையில் இயக்கிப் பதிவு செய்த வெளியீடு [Recorded Output] உள்ளது. src/volume2_companion/chapter15.py கோப்பில் கணிப்புமுறை [Algorithm] உள்ளது. tests/test_companion.py கோப்பில் அலகுச் சோதனைகள் [Unit Tests] உள்ளன. முதன்மை README_TA.md கோப்பில் நிறுவல் வழிகாட்டி [Setup Guide] உள்ளது.

உள்ளீட்டை [Input] மாற்றும் முன் நகலை [Copy] வைத்துக்கொள்ளவும். அலகுகளையும் [Units] கருதுகோள்களையும் [Assumptions] கவனிக்கவும். எதிர்பார்க்கப்பட்ட கோப்பை [Expected File] மாற்றுவது மட்டும் சரியான கணக்கீட்டிற்கான சான்று அல்ல. இணையம் [Network], கட்டண API [Paid API], அணுகல் சாவி [Credential] அல்லது மாதிரி பதிவிறக்கம் [Model Download] தேவையில்லை.
