# V2C18-CASE01: துணுக்குகள் மற்றும் எண்ணிக்கைகள் [Tokens and Counts]

வெளியீடு [Release] 0.1.0; தொகுதி 2, அத்தியாயம் 18. இது செயற்கைக் கற்றல் உள்ளீடு [Synthetic Teaching Fixture].

## நிரல் என்ன செய்கிறது [Program Behaviour]

BPE இணைப்பு வரிசை [Merge Ranking] நேரடியாக வழங்கப்படுகிறது; அது இங்கே கற்றுக்கொள்ளப்படுவதில்லை. நான்கு துணுக்குகளுக்கான [Tokens] எண்ணிக்கைகள் [Counts] [3,1,0,0]. ஒன்றைக் கூட்டும் சீராக்கம் [Add-one Smoothing] பயன்படுத்தப்படுகிறது. அளவளாவல் வளைவு [Scaling Curve] பரிமாணமற்ற செயற்கை மதிப்புகளிலிருந்து உருவாக்கப்பட்டது.

## முடிவைப் புரிந்துகொள்ளுதல் [Result Interpretation]

நிகழ்தகவுகள் [Probabilities] [0.5,0.25,0.125,0.125]; சராசரி எதிர்மறை மடக்கை வாய்ப்பு [NLL] 1.3862943611 nats; குழப்பளவு [Perplexity] 4. இது பெரிய மொழி மாதிரி [LLM] அல்ல. செயற்கைப் பொருத்தம் [Synthetic Fit] உண்மையான பயிற்சிச் செலவை [Training Cost] கணிக்காது.

## இயக்குதல் [Run]

துணைத்தொகுப்பின் முதன்மைக் கோப்புறையிலிருந்து [Companion Root]:

    python run_cases.py --chapter 18 --verify

fixture.json கோப்பில் உள்ளீடுகள் [Inputs] உள்ளன. expected.json கோப்பில் உண்மையில் இயக்கிப் பதிவு செய்த வெளியீடு [Recorded Output] உள்ளது. src/volume2_companion/chapter18.py கோப்பில் கணிப்புமுறை [Algorithm] உள்ளது. tests/test_companion.py கோப்பில் அலகுச் சோதனைகள் [Unit Tests] உள்ளன. முதன்மை README_TA.md கோப்பில் நிறுவல் வழிகாட்டி [Setup Guide] உள்ளது.

உள்ளீட்டை [Input] மாற்றும் முன் நகலை [Copy] வைத்துக்கொள்ளவும். அலகுகளையும் [Units] கருதுகோள்களையும் [Assumptions] கவனிக்கவும். எதிர்பார்க்கப்பட்ட கோப்பை [Expected File] மாற்றுவது மட்டும் சரியான கணக்கீட்டிற்கான சான்று அல்ல. இணையம் [Network], கட்டண API [Paid API], அணுகல் சாவி [Credential] அல்லது மாதிரி பதிவிறக்கம் [Model Download] தேவையில்லை.
