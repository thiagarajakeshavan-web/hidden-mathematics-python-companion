# V2C16-CASE02: தொகுதி இயல்பாக்கம் [BatchNorm]: பயிற்சி [Training], ஊகித்தல் [Inference], அச்சுகள் [Axes]

இது முன்னோக்கு மட்டும் கொண்ட இயல்பாக்கப் பயிற்சி [Forward-only normalisation lab]; பயிற்சிபெற்ற நரம்புவலைச் செயல்திறன் ஒப்பீடு [Trained neural-network benchmark] அல்ல. உள்ளீட்டு அணிகளின் [Input arrays] வடிவம் [Shape] (எடுத்துக்காட்டுகள், அம்சங்கள்). இது பயிற்சி BatchNorm [Training BatchNorm], வெளிப்படையாக வழங்கப்பட்ட உறைந்த புள்ளிவிவரங்களுடன் [Frozen statistics] ஊகித்தல் [Inference], தனியான BatchNorm/LayerNorm அச்சு ஒப்பீடு [Axis comparison] ஆகியவற்றைக் கணக்கிடுகிறது. Gamma, beta வழங்கப்பட்ட இணைநேரியல் மதிப்புகள் [Affine values]; பின்னோக்குக் கணக்கீடோ [Backward pass] அளவுருக் கற்றலோ [Parameter learning] இல்லை.

[[1],[3]] என்ற தொகுதி [Batch], gamma=[2], beta=[0.5], epsilon=1e-5 ஆகியவற்றில் பயிற்சிச் சராசரி [Training mean] 2; சார்புடைய முன்னோக்கு மாறுபாடு [Biased forward variance] 1. எப்சிலான் [Epsilon] வர்க்கமூலத்தின் [Square root] உள்ளே உள்ளது. வெளியீடுகள் தோராயமாக −1.499990, 2.499990. இயல்பாக்கிய மாறுபாடு [Normalised variance] 1/1.00001; துல்லியமாக ஒன்று அல்ல.

நகரும் புதுப்பிப்பு [Running update] PyTorch மரபைப் பின்பற்றுகிறது: rho=0.1 உடன் (1−rho)*old+rho*new. நகரும் மாறுபாடு [Running variance] மட்டும் சார்புடைய தொகுதி மாறுபாட்டின் [Biased batch variance] m/(m−1) மடங்கான சார்பற்ற மாறுபாட்டைப் [Unbiased variance] பயன்படுத்துகிறது. தொடக்க நகரும் சராசரி [Running mean] 0, மாறுபாடு [Variance] 1 என்றால் புதிய மதிப்புகள் 0.2, 1.1. இந்த நகரும் மாறுபாட்டு மரபிற்கு [Running-variance convention] m>1 தேவை என்பதால், இரண்டு எடுத்துக்காட்டுகளுக்குக் குறைவான பயிற்சியை [Training] செயலாக்கம் மறுக்கிறது.

ஊகித்தல் ஒப்பீடு [Inference comparison], சற்றுமுன் புதுப்பித்த பயிற்சி மதிப்புகளை [Training values] பயன்படுத்தாமல், தனியாக வழங்கப்பட்ட உறைந்த சராசரி [Frozen mean] 1, மாறுபாடு [Variance] 4-ஐப் பயன்படுத்துகிறது. வெளியீடுகள் 0.5, தோராயமாக 2.4999975. ஊகித்தல் [Inference] வழங்கப்பட்ட புள்ளிவிவரங்களை [Statistics] மாற்றாது; ஒரு எடுத்துக்காட்டையும் ஏற்கும். அதே ஊகித்தல் தொகுதியிலுள்ள [Inference batch] வேறொரு கோரிக்கை முதல் வெளியீட்டை மாற்றாது; பயிற்சித் தொகுதி [Training batch] மாற்றலாம்.

[[1,3],[5,7]] வரிசைகளில் BatchNorm நிரல்தோறும் வரிசைகளை ஒன்றுசேர்க்கிறது: சராசரிகள் [Means] [3,5], மாறுபாடுகள் [Variances] [4,4]. LayerNorm ஒவ்வொரு வரிசைக்குள்ளும் அம்சங்களை [Features] ஒன்றுசேர்க்கிறது: சராசரிகள் [Means] [[2],[6]], மாறுபாடுகள் [Variances] [[1],[1]]. அளவாக்கம் [Scale] ஒன்று, நகர்வு [Shift] பூஜ்ஜியம் என்றால் தோராய வெளியீடுகள் [[−1,−1],[1,1]] மற்றும் [[−1,1],[−1,1]]. எப்சிலான் [Epsilon] பருமன்களை [Magnitudes] சிறிது குறைக்கிறது. இந்த LayerNorm பயிற்சியிலும் [Training] ஊகித்தலிலும் [Inference] ஒரே தற்போதைய உள்ளீட்டுக் கணக்கீட்டைப் [Current-input calculation] பயன்படுத்துகிறது; நகரும் புள்ளிவிவர முறை [Running-stat mode] இல்லை.

செயலாக்கம் [Implementation] src/volume2_companion/chapter16_normalization.py-இல் உள்ளது. சோதனைகள் [Tests] இரு மாறுபாட்டு மரபுகளையும் [Variance conventions] இணைநேரியல் வெளியீடுகளையும் [Affine outputs] தனியாக வருவித்து, உறைந்த புள்ளிவிவர மாற்றமின்மை [Frozen-stat immutability], தொகுதிச் சார்பின்மை [Batch independence], இயல்பாக்க அச்சுகள் [Normalised axes] ஆகியவற்றைச் சோதிக்கின்றன. மாறாத தொகுதிகள் [Constant batches], ஒற்றை LayerNorm அம்சம் [Feature], பூஜ்ஜிய நகரும் மாறுபாடு [Running variance], செல்லாத பரிமாணங்கள் [Dimensions], எதிர்மறை நகரும் மாறுபாடு [Running variance], செல்லாத எப்சிலான் [Epsilon] ஆகியவை அடங்கும். சுருள் இடவியல் அச்சுகள் [Convolutional spatial axes], பகிர்ந்த புள்ளிவிவர ஒத்திசைவு [Distributed statistic synchronisation], பின்னோக்கு வகையிடல் [Backward differentiation], கட்டமைப்பு இயக்கச்சூழல் சார்பு [Framework runtime dependency] இதில் இல்லை.
