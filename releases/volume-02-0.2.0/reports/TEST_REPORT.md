## Independent review corrections included

Review uncovered a historical-data bug: a conflict available only after the decision cutoff could previously quarantine an earlier row. The released selector now determines known-at-cutoff records for the requested entity first, then assesses duplicates and conflicts. Regression tests verify that future information cannot erase the earlier A$12 observation.

Review also strengthened language-model probability validation and replaced probability ratios inside logarithms with differences of individual logarithms where needed. Cosine rescales vectors before norms and dot products. Quantization explicitly rejects a scale too small to represent in float64. None of these corrections changes the book's intended worked-example results.

The independent oracle file does not read expected.json. It derives answers from scalar formulas, exact fractions, permutation properties and separate objectives. This helps avoid merely confirming values generated by the same implementation.

## Reproducibility

From the extracted package root:

    python -W error -m unittest discover -s tests -v
    python run_cases.py --verify
    python verify_manifest.py

CASE_CONTRACTS.json records the exact synthetic inputs, outputs and chapter mapping. The bootstrap is NumPy PCG64, seed 23, 10,000 paired request resamples and linear percentile interpolation. SHA-256 file hashes detect changed bytes; they are not a publisher signature or security certification.

Core concept links for attention, DPO, LoRA, distillation and official Python/NumPy documentation were opened during this work. The code uses the installed, pinned versions; a newer documentation website does not imply that newer runtime was tested.

## Not tested or not implemented

- No clean internet dependency installation was performed. The tested environment already had the pinned NumPy. No Python/NumPy binaries are bundled.
- Windows, macOS, other Python/NumPy versions, GPU execution, cloud deployment, throughput, load, failure recovery and production observability were not tested.
- No production LLM, full tokenizer training, RLHF loop, learned semantic embedding model, RAG generator, vector database or LLM agent service is implemented.
- Synthetic labels and restrictions do not establish medical, nutritional, fairness, security or deployment safety. Prompt-injection resistance of a language model was not evaluated.
- The simulated quote is not live retailer pricing, an available meal kit, a delivery integration, a purchase or an allergen-safety guarantee.
- GitHub publication, unauthenticated public access and the author's licence selection remain pending. No credentials or publication actions were used.
- No mathematical test suite guarantees absence of every bug. This is a review teaching release, not a certified or retail-ready software product.
